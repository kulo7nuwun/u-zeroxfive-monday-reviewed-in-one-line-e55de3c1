A program that writes the funniest one-line review of my own Monday —
under 200 characters, a single line, no title, no explanation — to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> Monday: my alarm snoozed itself, my inbox hit 47 unread before coffee, and the 9 a.m. 'quick sync' is still going.
